A complete UCI chess engine in a single `main.py` (4,088 bytes), pure Python 3 standard library. Built for the make.fun tiny-chess-01 contest.

## Run it

```sh
python3 main.py
```

Then speak UCI (`uci`, `isready`, `position`, `go`, `quit`).
